# CafeMigna-Serrano

Sitio web de **Migna Café Restó** (Av. de los Incas 5321, CABA): menú digital, pedidos online, reservas y contacto.

```
CafeMigna-Serrano/
├── backend/    API REST en Node.js + Express (Entrega 2)
└── frontend/   Interfaz en React + Vite (Entrega 3)
```

## Cómo ejecutarlo

Se necesitan dos terminales (Node.js 18 o superior).

```bash
# Terminal 1: API en http://localhost:3000
cd backend
npm install
npm start
```

```bash
# Terminal 2: frontend en http://localhost:5173
cd frontend
npm install
npm run dev
```

Más detalle en [backend/README.md](backend/README.md) y [frontend/README.md](frontend/README.md).
